# 研究依据与设计决策

依据：2026-10-11 最新作品集 Handoff、九份项目交接与已上线中英文案例。这里公开归纳与边界，不公开参与者原始聊天、身份或个人饮食数据。

## 三个断点与四项策略

重复输入增加记录成本；数字需要解释；变化延迟使记录缺少即时回应。四项策略分别是轻量记录、看懂依据、温和回应、自愿共养。它们通向照片→候选→确认→回应→日记→可选计划/分享→家园积累。个人闭环先成立，关系参与保持可选。

## 自有行为探针

| 项目 | 归档事实 |
|---|---|
| 样本 | 20 人、10 组；5 对好友、5 对情侣 |
| 周期 | 三周 |
| 情境 | 参与者已有社交渠道中的餐食分享与回应 |
| 归档观察 | 9/10 组在观察期内持续分享餐食 |
| 缺失 | 逐日原始记录、明确频次阈值、对照组、长期追踪 |
| 可支持的判断 | 餐食分享与熟人回应值得继续探索 |
| 不能推出 | App 留存、因果关系、健康改善、平台效果高低 |

小红书用于观察健康内容如何被收藏和分享，抖音提供已有分享/共同对象的情境。平台选择不能当作渠道效果实验。旅程、对话插画与情绪曲线属于设计情境，不是参与者原话、肖像或实测满意度。

## 竞品与行业背景

竞品比较采用公开产品说明与归档定性研究，不用自拟评分暗示实测优劣。MyFitnessPal 有日记可见性与分享机制，Foodvisor 的公开介绍也包括养成和社区，因此不将竞品描述为“只有热量数字”。BiteSnap、卡迈的最新版本未完整实测，保留归档观察边界。

- [Foodvisor：官方商店介绍](https://play.google.com/store/apps/details?hl=en-US&id=io.foodvisor.foodvisor)
- [知萌 × HNC 2025 Z 世代健康消费报告](https://pdf.dfcfw.com/pdf/H3_AP202504221660293832_1.pdf)：2025 年 3 月、15 城市、18–30 岁、在线调查 N=1500；与项目 20 人探针独立。

公开报告只提供行业背景，不证明本项目方案有效；本仓库不复制整份第三方报告或品牌角色图。

## 下一轮验证问题

1. 用户能否区分角色表达、照片估算与本人感受？能否解释系统“为什么这样回应”？
2. 关心是否自愿、可跳过、可暂停？未分享是否被误读为没吃？
3. 家具与贴纸是否支持有意义的回顾，还是增加连续打卡压力？
4. 识别错误、无服务、记录不足时，用户能否继续完成自己的记录？
